# Harry's House of Cakes — website concept demo

A responsive React + Vite front-end concept for presenting a possible bakery website to Harry's House of Cakes. It takes general inspiration from bakery ecommerce patterns (collections, product cards, custom cake enquiry and WhatsApp ordering) without copying Mahie Bakery House's page or assets.

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

To create a production build, run `npm run build`.

## Before showing it to the business

- This is an unsolicited concept/demo, not an official Harry's House of Cakes website.
- Product names, photos, categories and prices are sample content and must be replaced with approved real information.
- Confirm the business name, address, phone number, operating hours, menu, pricing, delivery area and custom-order process with the owner.
- The public listing phone number is prefilled for the WhatsApp demo; verify with the owner before using it in a live site.
- The custom cake form opens a pre-filled WhatsApp message. It does not store submissions or accept payments.
- Photos are loaded from Unsplash URLs and need an internet connection.
- This project does not include a backend, database, order management, payment integration or admin dashboard.
- Get permission before using the business's branding, logo, customer reviews or real product photos publicly.

## Suggested client demo flow

1. Show the homepage on desktop and mobile.
2. Filter cake collections and open the custom cake enquiry modal.
3. Explain that order enquiries can start in WhatsApp, keeping the first version simple.
4. Ask the owner which products, prices, delivery details and order workflow they actually want.
5. Agree on scope and price before building or publishing a production website.
